# ADR-0003 도착 순서 대신 상태 우선순위로 판정

- 상태: 채택
- 날짜: 2026-11-11

## 맥락
SQS Standard는 순서를 보장하지 않고, 복구 경로는 원래 시점보다 늦게 들어온다. 웹훅에는 이벤트 발생 시각이 없다.

## 결정
주문 라인별 현재 상태보다 앞선 단계만 반영한다. 같은 단계면 단계별 시각이 더 늦은 쪽을 쓴다. 뒤로 가는 전이는 반영하지 않고 conflict로 남긴다. 클레임 상태는 별도 축으로 관리한다.

## 검토한 대안
- SQS FIFO + 주문번호 그룹으로 순서 보장: 수신 순서는 지켜도 복구 경로가 늦게 넣는 이벤트는 못 막는다. 처리량도 그룹 단위로 묶인다.

## 결과
순서와 무관하게 결과가 같다(F-04). FIFO 사용 여부와 그룹 키는 부하 측정 후 별도 ADR로 정한다.
