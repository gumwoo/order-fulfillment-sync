# ADR-0002 최종 기준은 조회 API

- 상태: 채택
- 날짜: 2026-11-11

## 맥락
샵바이는 실패한 웹훅을 다시 보내지 않고, 공식 문서도 주문 상태 조회 API를 함께 쓰라고 안내한다. 실패 웹훅 조회는 검색 범위가 7일이다.

## 결정
웹훅은 빠른 신호로만 쓴다. 실패 웹훅 조회(10분)와 `searchDateType=STATUS_CHANGE` 재조회(5분)를 돌리고, 하루 한 번 대사 배치로 차이를 기록한다. 각 경로의 마지막 성공 시각을 `sync_watermark`에 저장한다.

## 검토한 대안
- 웹훅만 사용: 유실 시 복구 수단이 없다.
- 조회만 사용: 지연이 폴링 주기만큼 늘고 호출량이 많다.

## 결과
호출량이 늘어 ADR-0004의 전역 레이트 리미터가 필요하다. watermark가 7일보다 오래되면 실패 웹훅 조회로는 복구할 수 없으므로 경보를 건다.
